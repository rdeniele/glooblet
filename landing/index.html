What's real

Six screens, built to actually do the thing

No fake DPI sliders, no fabricated hardware readouts. If something can't be done safely through a documented API, Glooblet says so instead of pretending.

Overview

Your current device, pointer config, active profile, and a one-click capability check, all read live, not assumed.

Mouse Settings

Real Windows pointer-speed and acceleration control, verified by reading the value back after every change, with one-click rollback.

Game Profiles

Per-game DPI, sensitivity, and notes with a cm/360° calculator, rated by confidence instead of pretending every game has a known constant.

Click Studio

Twelve original click sounds, your own uploads, and an optional low-level listener that plays a sound on click without ever touching the click itself.

Devices

Read-only mouse identification via Windows' own device APIs, no admin rights, no fake per-vendor DPI control.

Settings

Launch at startup via the standard per-user registry key, plus the full safety notice, always one click away.

Built to stay out of your games

Glooblet never reads or writes game memory, never injects code, and never automates gameplay. Everything it does is visible, user-mode, and built from documented Windows APIs. See the full policy in docs/SECURITY.md.

"Glooblet is designed to configure supported mouse and desktop settings without automating gameplay. Game compatibility depends on each game's policies, anti-cheat system, hardware, and the specific integration used. Glooblet does not guarantee that every third-party integration is permitted by every game."
